## 실행 방법

```
npm i

npm run dev

```

## 주요 기능

- 사이드바를 통한 가맹점 조회 및 거래내역 조회
- 거래내역 조회
  - 총 거래 건수, 결제 상태, 총 거래액 표현
  - 검색 및 필터 적용
  - 결제 수단에 따른 컬러 뱃지 적용
- 가맹점 조회
  - 검색 및 필터 적용
  - 활성 상태 및 업종에 따른 컬러 뱃지 적용
  - 가맹점 목록 클릭을 통한 가맹점 상세 정보(모달) 확인

## **스타일링 / CSS / UI 템플릿**

### 빠른 UI 작업을 위해 shadcn 사용

- `table, sidebar, tooltip, sheet, skeleton` : 대시보드 구성을 위한 컴포넌트, 로딩 표현
- `button` : 버튼 활용
- `input` : 검색어 입력
- `dialog` : 가맹점 상세 조회

- 반응형을 통해 모바일에서는 무한스크롤, pc에서는 버튼으로 페이지네이션이 되도록 했고, 실시간 검색 및 다중 필터링을 적용하여 원하는 것을 자유롭게 검색할 수 있도록 했으며, 컬러 코딩된 상태 뱃지와 스켈레톤으로 로딩 상태를 표현했습니다.
